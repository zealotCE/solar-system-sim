# 商业化与素材合规

本文记录太阳系模拟在接入赞助、广告、订阅或商业授权前需要处理的事项。它是工程侧风险清单，不构成法律意见，也不代表 NASA、JPL、ESA 或其他素材提供方认可本项目。

## 当前结论

项目可以商业化运营，但在程序化广告正式上线前，应先完成逐文件素材台账和灰色来源替换。代码、科学数据、纹理、模型和机构标志的权利边界不同，不能使用一个项目级许可证覆盖全部内容。

## 主要风险

| 范围 | 当前状态 | 商业化要求 |
| --- | --- | --- |
| 项目代码 | 仓库暂未提供 `LICENSE` / `NOTICE` | 明确自有代码许可证；第三方资产不得被项目许可证重新授权 |
| NASA 3D 模型与媒体 | 通常可用于信息、教育和模拟用途 | 保留来源；不得暗示 NASA 背书；NASA 标志、印章、员工肖像和第三方署名素材需要单独核查 |
| JPL 数据与媒体 | Horizons、近似行星位置等科学数据可用于模型；媒体可能含 Caltech 或第三方权利 | 保留数据来源；图片通常使用 `Courtesy NASA/JPL-Caltech`；逐项检查第三方例外 |
| NASA PDS 科学网格 | 67P、阿波菲斯、阿罗科斯等来自科学数据档案 | 保留数据集 DOI、产品标签中的 `CITATION_DESC` 和修改说明 |

| ESO 银河图 | CC BY 4.0 | 保留 `ESO / S. Brunier` 署名、许可证链接和修改说明 |

## 广告上线前的发布门槛

1. 建立 `THIRD_PARTY_ASSETS.md`：记录每个模型、纹理、图片和字体的本地路径、来源 URL、作者、许可证、修改方式与下载日期。
2. 替换或取得许可：优先处理 Planet Pixel Emporium 衍生纹理与来源不完整的示例纹理。
3. 分离许可证：自有代码许可证与第三方素材声明分开，避免声称拥有 NASA/PDS/CC 素材版权。
4. 增加公开页面：来源与署名、隐私政策、使用条款、联系方式和免责声明。
5. 默认采用上下文或非个性化广告；面向 EEA、英国和瑞士时使用 Google 认证 CMP。
6. 广告位不得遮挡画布目标、标签、时间控制或底部工具栏，也不得诱导、奖励或暗示用户点击广告。
7. 广告脚本在首屏和许可确认后延迟加载，防止影响 WebGL 内存、LCP 和交互帧率。

## Hash 深链与真实路径

现有链接：

```text
/#target=earth&date=2028-04-15
/#target=newhorizons&date=2028-04-15
```

已经完整实现模拟状态分享：目标、日期、语言和真实比例均可组合，且静态托管不需要 SPA 回退。这类链接适合用户分享，但 `#` 后的 fragment 不会发送给服务器。对搜索引擎、社交预览和广告审核而言，上述链接通常仍是同一个 `/` 页面，无法分别设置 canonical、标题、描述和结构化数据。

项目现已采用兼容的混合结构：

```text
/objects/earth#date=2028-04-15
/missions/newhorizons#date=2028-04-15
```

- 构建时为全部 65 个目标生成真实 HTML，路径负责可索引的目标档案、canonical、Open Graph 与 JSON-LD；
- Hash 参数继续负责日期、比例、语言和其他动态模拟状态；
- 旧的 `#target=...` 链接继续兼容；
- Cloudflare Pages 为每个已知路径生成真实 HTML，避免使用会把缺失 GLB 错误重写成 HTML 的全局 catch-all。

可选构建环境变量 `PUBLIC_SITE_URL=https://你的域名` 用于生成绝对 canonical；未配置时使用可由浏览器和搜索引擎解析的站点根相对路径。

## 后续商业功能

教育版或专业版暂不进入当前实现，候选方向包括无广告模式、课堂演示、保存与分享场景、高分辨率导出、课程时间线、嵌入组件以及学校/展馆授权。开始开发前应先用匿名统计验证使用频率、受众地区和愿付费场景。
