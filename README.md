# 太阳系模拟

交互式三维太阳系演示：八大行星、月球、小行星带、开普勒简化椭圆轨道，以及中文控制面板。适合作为 Cursor 从脚手架到可运行预览的完整工作流样例。

## 功能

- 写实风格的太阳、八大行星与月球（相对周期真实，尺寸适度夸张）
- 火星与木星之间约 2600 颗实例化小行星
- 半透明椭圆轨道线、程序化星空、太阳辉光
- 点击天体查看直径、公转/自转周期与简介
- 跟随模式：镜头锁定所选天体
- 暂停 / 播放，时间倍率 1x–1000x
- 轨道线、名称标签开关，一键重置相机
- 桌面右侧信息卡，移动端底部抽屉

## 环境

- Node.js 20+
- 包管理器：npm

## 安装与运行

```bash
npm install
npm run dev
```

开发服务器固定监听 **4317** 端口：

[http://localhost:4317](http://localhost:4317)

生产构建：

```bash
npm run build
npm run preview
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动 | 旋转视角 |
| 滚轮 / 捏合 | 缩放 |
| 单击行星 / 太阳 / 月球 | 打开档案 |
| 时间滑块 | 1x 约等于「1 真实秒 = 1 地球日」 |
| 跟随 | 相机目标锁定当前天体 |
| 重置相机 | 回到总览并取消跟随 |

## 技术栈

Vite + React + TypeScript、@react-three/fiber、@react-three/drei、@react-three/postprocessing、Tailwind CSS、shadcn/ui 风格组件。
